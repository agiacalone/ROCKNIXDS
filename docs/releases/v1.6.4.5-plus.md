# ROCKNIXDS 1.6.4.5-plus for the RG DS Plus (agiacalone fork)

- **The new shaders in the menu.** *Nintendo DS > Shader* now lists 19 more shaders, after the ds-* ones: libretro's
  bevel, fxaa, lcd1x, lcd1x-nds, nds-color, retro-v2, sharp-bilinear + scanlines, zfast-crt and zfast-lcd; DraStic's
  own lcd1x, quilez, sharp-bilinear and zfast-lcd (some with NDS color); and Anbernic NNDDSS's Dot MiZai and retro
  tiles. SuperDrastic rocknixds.11 brought them, but until now only the in-game menu offered them. sharp-bilinear and
  lcd3x were already in the list as ROCKNIX's own.

Everything in 1.6.4.4-plus stays. The change is `dsflip/device/es-features.sh`.

Update from the menu (*Updates & downloads > ROCKNIXDS*), or install over ssh on a handheld running ROCKNIX:

```sh
curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/main/install.sh | sh
```
