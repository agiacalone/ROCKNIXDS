# ROCKNIXDS 1.6.4.4-plus for the RG DS Plus (agiacalone fork)

- **Launches from the network start at once.** While the menu was idle, a game launched through EmulationStation's
  HTTP API (the Store, scripts, tools) started only at the next full minute. It now starts in about 6 seconds, as a
  launch from the pad does. Idle power use is unchanged.
- **SuperDrastic 0.5.0-beta.1-rocknixds.12**, the second set of fixes brought over from the BananaOS line:
  - **Quit without saving:** X on the quit question (it asks again), or the new button. Save and quit stays the first
    choice.
  - A quit sent while the in-game menu is open (a shutdown, the exit hotkey's kill) now closes the menu and quits.
  - **Experimental, off unless switched on:** low latency (`DSFLIP_LOWLAT=1`; rougher on the RG DS Plus), a sleeping
    sound wait (`DSFLIP_AUDIO_WAIT=1`) and a gentler CPU governor rule (`DSFLIP_CPUGOV_SPIKE=1`). Frame pacing and
    sound are as in 1.6.4.3-plus by default.

Everything in 1.6.4.3-plus stays. The engine's source is `dsflip/superdrastic-0.5.0-beta.1-rocknixds.12.patch` and the
[rocknixds-12](https://github.com/agiacalone/SuperDrastic/tree/rocknixds-12) branch; `SUPERDRASTIC` says how it was
checked. The EmulationStation change is `dii-ess-aye/es-rgds-apiwake.patch`.

Update from the menu (*Updates & downloads > ROCKNIXDS*), or install over ssh on a handheld running ROCKNIX:

```sh
curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/main/install.sh | sh
```
