# ROCKNIXDS 1.6.3.2 for the RG DS (agiacalone fork, beta)

**This is a beta.** It brings the RG DS up to the RG DS Plus's 1.6.4.4-plus. The changes ran on an RG DS Plus only:
no RG DS has run this release yet. The stable channel stays on 1.6.3.1 until someone has. To try it, switch the
ROCKNIXDS update channel to **Beta** in *Updates & downloads*, then update. Please report what you find.

- **SuperDrastic 0.5.0-beta.1-rocknixds.12** (was rocknixds.9-test.6), the same package as 1.6.4.4-plus:
  - The audio crackle fix from upstream's 1.6.4 for the Plus: DraStic's sound no longer runs out in heavy 3D scenes.
  - No long white screen after a long sleep (BananaLinux #64).
  - 21 more shaders (libretro's, DraStic's and Anbernic NNDDSS's), in the in-game menu and in
    *Nintendo DS > Shader*.
  - Save and load state pop-ups, and a charger shown as charging.
  - **Quit without saving:** X on the quit question (it asks again), or the new button.
  - A quit sent while the in-game menu is open now closes the menu and quits.
- **Launches from the network start at once.** A game launched through EmulationStation's HTTP API (the Store,
  scripts, tools) started only at the next full minute while the menu was idle. It now starts in about 6 seconds.
- **60 Hz panels by default** (upstream #86). `--no-60hz` keeps 59.8 Hz; the choice is remembered.
- **The menu gets the pad back after a DS game** (upstream #89).
- **The Store, Bank & Trade and Döda Kvarter come from this fork,** so they keep working whatever happens upstream.
- **No performance-log upload.** 1.5 to 1.6.3.1 could upload a log to upstream's queue when you allowed it. This fork
  doesn't collect them, so the upload, its first-launch question and the *Share performance logs* option are gone.

The engine's source is `dsflip/superdrastic-0.5.0-beta.1-rocknixds.11.patch` and `.12.patch`, and the
[rocknixds-12](https://github.com/agiacalone/SuperDrastic/tree/rocknixds-12) branch. The EmulationStation change is
`dii-ess-aye/es-rgds-apiwake.patch`.

Or over ssh on an RG DS running ROCKNIX (`root`, password `rocknix`):

```sh
sed -i 's/^rocknixds.channel=.*/rocknixds.channel=beta/' /storage/.config/system/configs/system.cfg
curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/main/install.sh | RGDS_BRANCH=beta sh
```

Back to 1.6.3.1: switch the channel to **Stable**; the menu then offers 1.6.3.1.
