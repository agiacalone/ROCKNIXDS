# ROCKNIXDS 1.6.4.8-plus for the RG DS Plus (agiacalone fork)

- **SuperDrastic comes back after a ROCKNIX update.** ROCKNIX 20261101 resets every standalone emulator's settings
  the first time it starts after an update from an older ROCKNIX. That deleted DraStic's folder, and SuperDrastic
  with it, so DS games ran on stock DraStic until ROCKNIXDS was installed again.
  - Now ROCKNIXDS checks at every start. If SuperDrastic is missing, it installs the same ROCKNIXDS version again
    once Wi-Fi is up, then says so in the menu.
  - Your saves and save states are not touched. DraStic options you changed yourself need setting again.
  - A ROCKNIX update also replaces the screen timing, so the menu asks for one restart to bring back 60 Hz.
  - If there is no Wi-Fi within 10 minutes, the menu says so. Turn Wi-Fi on and restart, or reinstall from
    *Updates & downloads > ROCKNIXDS*.
- An install made with `--no-dsflip` is remembered, so it is never taken for a reset.
- **The Beta update channel follows each release**, so it never offers an older build.

**Updating ROCKNIX from 20261001 or older?** Update ROCKNIXDS to this release first. If you already updated
ROCKNIX, reinstall ROCKNIXDS once from *Updates & downloads > ROCKNIXDS*.

Everything in 1.6.4.7-plus stays.

Update from the menu (*Updates & downloads > ROCKNIXDS*), or install over ssh on a handheld running ROCKNIX:

```sh
curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/main/install.sh | sh
```
