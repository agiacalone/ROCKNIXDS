# ROCKNIXDS 1.6.4.1-plus for the RG DS Plus (agiacalone fork)

ROCKNIXDS 1.6.4-plus with fixes that are open as pull requests upstream, hosted here until
[JorreFog/ROCKNIXDS](https://github.com/JorreFog/ROCKNIXDS) has them.

- Any theme with a dual-screen layout uses both screens and shows in the theme menu
  ([#84](https://github.com/JorreFog/ROCKNIXDS/pull/84), [#85](https://github.com/JorreFog/ROCKNIXDS/pull/85)).
- The screensaver on the top panel, the bottom backlight off while it runs, and long names on one line
  ([#69](https://github.com/JorreFog/ROCKNIXDS/pull/69)).
- The slideshow wakes only when its clock changes ([#71](https://github.com/JorreFog/ROCKNIXDS/pull/71)).
- More about the game on the library's top screen ([#72](https://github.com/JorreFog/ROCKNIXDS/pull/72)).
- A charging battery and coloured status icons ([#73](https://github.com/JorreFog/ROCKNIXDS/pull/73)).
- Touch controls on the bottom panel during the screensaver, with the theme's status icons
  ([#75](https://github.com/JorreFog/ROCKNIXDS/pull/75)).

Install over ssh on a handheld running ROCKNIX:

```sh
curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/main/install.sh | sh
```
