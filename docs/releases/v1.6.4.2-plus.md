# ROCKNIXDS 1.6.4.2-plus for the RG DS Plus (agiacalone fork)

ROCKNIXDS 1.6.4.1-plus, now maintained in this fork on base ROCKNIX. Upstream
([JorreFog/ROCKNIXDS](https://github.com/JorreFog/ROCKNIXDS)) stopped on 2026-10-22 and moved to
[BananaOS](https://github.com/JorreFog/BananaLinux); this fork carries ROCKNIXDS on.

- **The Store, Döda Kvarter and Bank & Trade come from this fork.** The Store reads its catalog and the apps'
  releases here, and Bank & Trade's releases (`bank-v0.1.0`, `bank-v0.2.0`) are mirrored unchanged. eReaderDS
  still comes from its own author.
- **The menu answers the pad after a DS game.** Focus goes back to EmulationStation when the panels return to the
  menu ([#89](https://github.com/JorreFog/ROCKNIXDS/issues/89)).
- **60 Hz panels by default** ([#86](https://github.com/JorreFog/ROCKNIXDS/issues/86)). The RG DS Plus's panels go
  from 60.17 to 60.0027 Hz, DraStic's frame rate, after one reboot. The installer checks the live pixel clock and
  the stock timing first and keeps a backup of the device tree in `/storage`. `--no-60hz` turns it off and is
  remembered.
- The README says what this fork is and that it works with base ROCKNIX.

Everything in 1.6.4.1-plus stays: any dual-screen theme, the top-panel screensaver with touch controls, the slideshow
wake fix, game details and the charging battery
([#69](https://github.com/JorreFog/ROCKNIXDS/pull/69), [#71](https://github.com/JorreFog/ROCKNIXDS/pull/71),
[#72](https://github.com/JorreFog/ROCKNIXDS/pull/72), [#73](https://github.com/JorreFog/ROCKNIXDS/pull/73),
[#75](https://github.com/JorreFog/ROCKNIXDS/pull/75), [#84](https://github.com/JorreFog/ROCKNIXDS/pull/84),
[#85](https://github.com/JorreFog/ROCKNIXDS/pull/85)).

Update from the menu (*Updates & downloads > ROCKNIXDS*), or install over ssh on a handheld running ROCKNIX:

```sh
curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/main/install.sh | sh
```
