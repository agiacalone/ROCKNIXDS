# ROCKNIXDS 1.6.3.3 for the RG DS (agiacalone fork, beta)

**This is a beta,** like 1.6.3.2, which it builds on. No RG DS has run either release yet; the changes ran on an
RG DS Plus only. The stable channel stays on 1.6.3.1 until someone has. To try it, switch the ROCKNIXDS update
channel to **Beta** in *Updates & downloads*, then update. Please report what you find.

- **DS games count as played again** (upstream #50, #62, #88). With fast switching on, the default, a DS game that
  was quit normally came back to EmulationStation as a failed launch. Play count, time played and last played never
  changed. ROCKNIX's `start_drastic.sh` ends by killing gptokeyb, and that kill is the launch's exit status. ROCKNIXDS
  had already stopped gptokeyb, so the kill failed. The DraStic wrapper now leaves a process of that name for it.
- **A Store update cut short no longer loses an app's saves.** An update moved the files an app keeps (Döda
  Kvarter's scores and saved run, the Store's own data) into the new copy before swapping folders. A power cut at
  that moment left the only copy in a folder that the next install deleted first. The Store now copies those files,
  and the next install puts back anything a cut-short update left behind.

Both fixes are upstream's (JorreFog/ROCKNIXDS commits `38c389d` and `7487b02`, which were never merged into its
`main`). Everything in 1.6.3.2 stays.

Or over ssh on an RG DS running ROCKNIX (`root`, password `rocknix`):

```sh
sed -i 's/^rocknixds.channel=.*/rocknixds.channel=beta/' /storage/.config/system/configs/system.cfg
curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/main/install.sh | RGDS_BRANCH=beta sh
```

Back to 1.6.3.1: switch the channel to **Stable**; the menu then offers 1.6.3.1.
