# ROCKNIXDS 1.6.3.4 for the RG DS (agiacalone fork, beta)

**This is a beta,** like 1.6.3.2 and 1.6.3.3, which it builds on. No RG DS has run these releases yet; the changes
ran on an RG DS Plus only. The stable channel stays on 1.6.3.1 until someone has. To try it, switch the ROCKNIXDS
update channel to **Beta** in *Updates & downloads*, then update. Please report what you find at
<https://github.com/agiacalone/ROCKNIXDS/issues>.

- **GBA DS in the Store**, by kyannon (GPL-3.0). It plays Game Boy Advance games on one screen and shows the game's
  own map, race display or unit details on the other, for 37 games including Castlevania, Metroid, Zelda and Golden
  Sun. It finds the games in `/storage/roms/gba`. Its save states and settings stay when it is updated or removed,
  and it updates itself too.
- **SuperDrastic 0.5.0-beta.1-rocknixds.13** (was rocknixds.12), the same package as 1.6.4.7-plus:
  - A button or direction released while the in-game menu is open is now released in the game too. Before, the game
    kept it held after the menu closed.
  - If a save on quit does not finish (a full card, or the 5-second limit), the previous resume state stays.
  - A build with stronger security checks no longer stops at start-up.
  - The NNDDSS shaders scale correctly, and the Retro tiles shader no longer shows a washed-out half.
- **A changelog**: `CHANGELOG.md` lists every fork release.

Everything in 1.6.3.3 stays. The engine's source is `dsflip/superdrastic-0.5.0-beta.1-rocknixds.13.patch` and the
[rocknixds-13](https://github.com/agiacalone/SuperDrastic/tree/rocknixds-13) branch.

Or over ssh on an RG DS running ROCKNIX (`root`, password `rocknix`):

```sh
sed -i 's/^rocknixds.channel=.*/rocknixds.channel=beta/' /storage/.config/system/configs/system.cfg
curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/main/install.sh | RGDS_BRANCH=beta sh
```

Back to 1.6.3.1: switch the channel to **Stable**; the menu then offers 1.6.3.1.
