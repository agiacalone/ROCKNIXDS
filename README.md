# TechDweeb theme on both screens

This installs ROCKNIXDS with the dual-screen theme fix from
[#84](https://github.com/JorreFog/ROCKNIXDS/pull/84) and [#85](https://github.com/JorreFog/ROCKNIXDS/pull/85),
then [TechDweeb's theme](https://github.com/anthonycaccese/techdweeb-es) and switches to it.

1. On an RG DS or RG DS Plus running ROCKNIX, connect over ssh as `root` (password `rocknix`).
2. Run:

   ```sh
   curl -fsSL https://raw.githubusercontent.com/agiacalone/ROCKNIXDS/techdweeb-preview/install-preview.sh | sh
   ```

The next ROCKNIXDS update from the menu goes back to the stock release until the fix is merged.
